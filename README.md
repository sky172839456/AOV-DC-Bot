# AOV-DC-Bot

《傳說對決》官方新聞 Discord 通知機器人。

## 監控範圍

- 公告
- 活動
- 系統
- 賽事
- 教學

程式會分別掃描各分類，以公告 ID 去除重複內容。預設回查最近 30 天，讓官網延後刊登、回填日期或列表排序異常的文章仍有機會被補抓；已經成功發送過的 ID 不會再次通知。

`攻略` 位於官方另一套內容網站，不屬於新聞公告清單，目前不混入本通知頻道。

## 環境設定

- `WEBHOOK_URL`：正式通知頻道
- `TEST_WEBHOOK_URL`：測試通知頻道
- `AOV_BACKFILL_DAYS`：近期回查天數，預設 `30`
- `AOV_ID_BACKFILL_WINDOW`：相對最新公告編號的回補範圍，預設 `200`

手動執行 GitHub Actions 只會將各分類範例送至測試頻道；排程執行才會發送新的正式公告。
